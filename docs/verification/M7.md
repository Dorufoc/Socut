## M7-A 文本元素数据模型 · 已完成

**定位**：文本元素是"可自由摆放的叠加文字"（新闻标题 / 人名条 / 引语 / 数字 / 地点 / 时间戳 / 角标），
与「包装里的字幕条」是两套东西：字幕条走 8 套广播预设 + 安全区/擦除纪律；文本元素走 7 套起始预设 + 自由样式。

| 项 | 位置 | 说明 |
|---|---|---|
| 类型 | `src/shared/types.ts` `TextElementClip` / `TextElementStyle` / `TextElementAnimation` / `TextElementPresetId` | 像素按 1080p 基准声明；`startTime/endTime` 秒；`trackId` 固定 `track-text` |
| 预设 | `src/shared/textPresets.ts` | 7 套（newsHeadline/personTag/quoteCard/numberStat/locationTag/timestamp/cornerBadge）+ `resolveTextStyle`（预设→覆盖逐字段合并 + 夹取）+ `validateTextPresets` 自检 |
| schema | `src/shared/projectSchema.ts` | `normalizeTextElementClip` / `normalizeTextStyleOverrides` / `normalizeTextElementAnimation` / `createTextElementClip`；空白文案整条丢弃、未知预设回退默认、颜色非法整键丢弃、时长夹 0.05–2s、上浮量 0–200px |
| 落盘 | `Project.textClips?` / `SequenceSnapshot.textClips?` | 缺省不写键（旧工程 JSON 形状不变）；多序列切换一起搬（`sequence.ts`） |
| 时长包络 | `src/shared/presetResolver.ts` `projectDurationSec/projectSpanSec/activeStartFrame` | 只有文本元素、没有字幕条时导出区间也覆盖（否则导出为空） |

**取证**：`tests/textElements.test.ts`（预设自检、合并夹取、归一丢弃、默认键不出现、job 区间）。

## M7-B 渲染接线 · 已完成（第一批）

- `src/renderer/src/render/textElement.ts`：Canvas2D 绘制，字号/边距/阴影/描边按 `height / 1080` 缩放；
  动画 = 淡入淡出 + 上浮；支持关键帧（复用 M6 `resolveClipParams`：不透明度/位移/缩放/旋转）。
- `src/renderer/src/render/renderer.ts`：先画文本元素、再画字幕条（文本在字幕条之下）；无文本元素时零开销。
- `src/renderer/src/render/jobBuilder.ts`：`ResolvedTextElement`（合并预设/覆盖/字体 family/帧区间）；`RenderJobSpec.textClips?`。
- 效果：**预览与导出走同一个 `renderFrame`**，因此透明 MOV / 叠层 MP4 的图形层天然带上文本元素，无需改 FFmpeg 图。

**取证**：`tests/textElements.test.ts` 用录制式假上下文断言——稳态帧落字、入场首帧 alpha < 0.2、稳态 alpha = 1、末帧不再落笔、带背景板的预设先画板后画字、时间窗外不画。

## M7-F 媒体段卡片关键帧菱形 · 已完成（M6 遗留 UI 收尾）

`src/renderer/src/timeline/MediaClipCard.tsx`：

- 每条媒体段按 `clip.keyframes` 所有参数轨的 `t` **并集**画菱形（同一 `t` 只画一个；`t ∈ [0,1]` 是片段内进度），
  落点 `t × 卡片实际宽度`（与 `style.width` 的 24px 下限一致），贴顶 6px 避免压住预览条/频谱/文字；
- 点击菱形：`onSeekKeyframe(入点 + t × 时长)`，由 `Timeline` 统一 `snapTimeToFrame` 后 seek 并暂停播放；
  `pointerdown` 上 `stopPropagation`，**不会**顺带启动整段拖动/改变选中；
- 顺手修样式 bug：`.clip-card__keyframe` 之前是 `pointer-events: none`（菱形看得见但点不到），
  改成 `auto` 后字幕条卡片与媒体段卡片的关键帧跳转都真正可用。

**取证**

```
npx vitest run src/renderer/src/timeline/MediaClipCard.test.tsx src/renderer/src/timeline/Timeline.test.tsx
# 68 例全绿（新增 2 例：t 并集去重 + 点击跳到 5s 且不触发 onMove；无关键帧时 DOM 里没有菱形）
```

## M7-E 特效包机制 · 已完成（第二批）

`src/shared/effectPackages.ts` = **manifest + 参数 schema + FFmpeg 实现**三件套（不 import 任何东西，
`types.ts` 反向引用其类型）：

| 包 | 参数 | FFmpeg 实现 | 预览近似 |
|---|---|---|---|
| 暗角 vignette | intensity 0–100（默认 60） | `vignette=angle=…` | brightness 略降 |
| 胶片颗粒 filmGrain | strength 0–100（默认 18） | `noise=alls=N:allf=t+u` | 无（导出侧） |
| 故障 glitch | amount 0–20px（默认 6） | `rgbashift=rh=N:bh=-N` | 无 |
| 色差偏移 chromaShift | amount 0–40px（默认 8） | `chromashift=cbh=N:crh=-N` | 无 |
| 暖色漏光 warmLeak | strength 0–100（默认 40） | `colorbalance=…` | `sepia(…)` |
| 黑白 monochrome | contrast 0–100（默认 40） | `hue=s=0,eq=contrast=…` | `grayscale(1)` |

纪律：
- **默认值不落盘**：`normalizeActiveEffects` 只保留非默认参数；`effects` 为空时整键删除，旧工程与新 argv 逐字节不变；
- 归一化：未知 id 丢弃、同 id 后者覆盖、参数夹到 schema 范围、上限 8 个包；
- 导出顺序：调色之后、`format=<pix_fmt>` 之前；有几何变换时挂在 `overlay` 之后（作用于整幅画面）；
- 预览侧只做能近似的三项（黑白/暖光/暗角），其余靠导出——与降噪/防抖的"导出侧生效"口径一致。

## M7-E 图形层 z 档（`graphicsZ`）· 已完成（第三批）

**语义**：字幕条 + 文本元素这一整层（"图形层"）相对媒体层的层级。

| 值 | 预览 | 导出 |
|---|---|---|
| `aboveMedia`（缺省，不落盘） | Canvas `z-index:2` 压在媒体视频 `z-index:1` 上 | 媒体基座在下，透明帧层按时间窗叠在上（与旧 argv 逐字节一致） |
| `belowMedia` | 画面框加 `stage__frame--graphics-below`：Canvas 降到 1、媒体升到 2 | 透明帧层作为基座，媒体基座整体叠在它上面（媒体不透明处盖住字幕；媒体结束由 `eof_action=pass` 露出字幕层） |

**实现要点**
- 类型：`GraphicsZ = 'aboveMedia' | 'belowMedia'`；`Project.graphicsZ`、`SequenceSnapshot.graphicsZ`（随序列切换搬运）、`ExportRequest.overlay.graphicsZ`；
- schema：只保留 `belowMedia`（默认不落盘）→ 旧工程 JSON 与旧 argv 不变；
- 滤镜图：抽出 `subtitleOverlayChains(input, baseLabel)`，单轨基座 / 转场基座 / 多轨基座 / 单输入直接管道四处共用；
  `belowMedia` 分支输出 `[<overlay>:v]fps=..,setsar=1[obase]` + `[obase][<base>]overlay=0:0:...`；
- 透传：渲染侧 `exportRunner` → 主进程 `engine` → `OverlayRunCtx` → 两条 direct-pipe builder；
- 入口：导出面板「高级」的「图形层位置」下拉、CLI `project.graphicsZ`、MCP `project_graphics_z`。
